# ⚡ Inicio Rápido

### PowerShell (Recomendado):
```powershell
.\inicio.ps1
```

### CMD:
```cmd
.\inicio.bat
```

---

## 📋 Menú Interactivo

El script te mostrará un menú con estas opciones:

```
[1] Inicio Rápido (dev)
    └─ Inicia el sistema (uso diario)

[2] Setup Completo
    └─ Instala dependencias y configura todo

[3] Reset Base de Datos
    └─ Elimina y recrea la base de datos

[4] Solo Instalar Dependencias
    └─ npm install en todos los workspaces

[5] Solo Configurar Prisma
    └─ Genera cliente y sincroniza BD

[0] Salir
```

---

## 🚀 Uso Recomendado

### 🆕 Primera vez:
1. Ejecuta `.\inicio.ps1` (o `.\inicio.bat`)
2. Selecciona opción **[2] Setup Completo**
3. Espera a que termine
4. El sistema se iniciará automáticamente

### 📅 Uso diario:
1. Ejecuta `.\inicio.ps1` (o `.\inicio.bat`)
2. Selecciona opción **[1] Inicio Rápido**
3. ¡Listo!

### 🔄 Limpiar base de datos:
1. Ejecuta `.\inicio.ps1` (o `.\inicio.bat`)
2. Selecciona opción **[3] Reset Base de Datos**
