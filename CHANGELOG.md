## [1.0.0] - 2026-02-02

### Agregado
- ✨ Sistema completo de gestión escolar
- 👥 Gestión de usuarios (Admin, Profesores, Estudiantes, Tutores)
- 📚 Gestión académica (Ciclos escolares, Períodos, Aulas, Materias)
- 📊 Sistema de calificaciones
- 📅 Control de asistencia con justificaciones
- 🕐 Gestión de horarios por aula
- 📝 Actividades (Tareas, Exámenes, Proyectos)
- 📈 Dashboard con estadísticas
- 🔐 Autenticación con JWT
- 🎨 Interfaz moderna con Next.js y TailwindCSS
- ⚡ API rápida con Fastify
- 💾 Base de datos SQLite con Prisma ORM
- 📱 Diseño responsive
- 🌐 Soporte para múltiples ciclos escolares
- 🔄 Sincronización automática de estados de ciclos escolares
- 📊 Estadísticas académicas por estudiante
- 👨‍🏫 Perfil de profesores con historial de secciones guía
- 🎯 Asignación de materias a aulas
- 📋 Gestión de estudiantes por aula
- 🔔 Sistema de notificaciones básico
